# NIGHT SURVIVORS — 어둠의 생존자

뱀파이어 서바이버즈 스타일의 웹 게임입니다. 순수 HTML + CSS + JavaScript(Canvas 2D)로 만들었고,
외부 라이브러리·빌드 도구·이미지/사운드 파일이 없습니다. 효과음은 Web Audio API로 실시간 합성합니다.

## 실행 방법

- `index.html`을 **더블클릭**해서 브라우저로 열면 바로 실행됩니다.
- (선택) 로컬 서버로 열기: `npx serve .` 또는 `python3 -m http.server` 실행 후 표시된 주소로 접속

## 조작법

| 동작 | 키 |
|---|---|
| 이동 | WASD / 방향키 (모바일·마우스: 화면을 누른 채 드래그 → 가상 조이스틱) |
| 공격 | 자동 |
| 일시정지 | ESC / P (화면 우측 상단 II 버튼) |
| 음소거 | M (우측 상단 소리 버튼) |
| 레벨업 선택 | 카드 클릭 또는 1 / 2 / 3 |
| 재시작 (게임오버) | R 또는 Enter |
| FPS 표시 | F (또는 주소 뒤에 `?debug`) |

창이 비활성화되면 자동으로 일시정지됩니다. 최고 기록과 음소거 설정은 localStorage에 저장됩니다.

## 게임 규칙

- 적은 화면 밖에서 나타나 플레이어를 쫓아옵니다. 시간이 지날수록 스폰 수·체력·공격력이 오릅니다.
- 1분마다 사방에서 적이 몰려오는 **포위 공격**, 2분마다 **보스**가 등장합니다.
- 적을 처치하면 경험치 젬이 떨어지고, 가까이 가면 자석처럼 빨려옵니다. 레벨업하면 게임이 멈추고 3개 중 1개를 고릅니다.
- 가끔 떨어지는 아이템: **빨간 십자**(체력 20 회복), **파란 자석**(맵의 모든 젬 흡수).
- 체력이 0이 되면 게임오버. 생존 시간·처치 수·도달 레벨이 표시됩니다.

## 적

| 이름 | 특징 |
|---|---|
| 구울 (빨간 원) | 기본형 |
| 박쥐 (보라 삼각형) | 빠르고 약함. 30초쯤부터 등장 |
| 골렘 (초록 사각형) | 느리지만 단단하고 아픔, 넉백에 강함. 2분부터 등장 |
| 밤의 군주 (보스) | 2분마다 등장. 돌진 전 붉은 예고선을 표시하고, 주기적으로 탄환을 원형으로 발사. 처치 시 대량 젬 + 회복 + 자석 |

## 무기 (최대 6종, 각 Lv 1~5)

| 무기 | 설명 | 레벨업 효과 |
|---|---|---|
| 마법탄 | 가장 가까운 적에게 탄환 발사 (시작 무기) | 데미지·발사 수·관통 증가, 쿨다운 감소 |
| 수호 오브 | 플레이어 주위를 회전하며 닿는 적 공격 | 구슬 수·반경·크기·회전속도 증가 |
| 화염 노바 | 주기적으로 주변에 폭발, 적을 밀어냄 | 데미지·범위 증가, 쿨다운 감소 |
| 관통 칼날 | 이동 방향으로 적을 꿰뚫는 칼날 | 개수·관통 수 증가 |
| 천둥 번개 | 화면 안의 무작위 적에게 낙뢰 (범위 피해) | 낙뢰 수·범위 증가 |
| 회전 도끼 | 위로 던져 포물선을 그리며 모든 적 관통 | 개수·크기·데미지 증가 |

## 패시브 (각 Lv 1~5)

| 패시브 | 효과 (레벨당) |
|---|---|
| 신속의 장화 | 이동속도 +10% |
| 강철 심장 | 최대 체력 +20 (즉시 회복) |
| 시간의 모래 | 모든 무기 쿨다운 -8% |
| 자력의 부적 | 젬 흡수 범위 +35% |
| 힘의 반지 | 모든 무기 데미지 +10% |

모든 무기·패시브를 최대로 올리면 레벨업 보상으로 **생명의 물약**(체력 40 회복)이 나옵니다.

## 밸런스 조정

`game.js` 맨 위의 `CONFIG` 객체에 모든 수치(플레이어 스탯, 경험치 곡선, 스폰 속도·난이도 곡선,
보스 주기, 드랍 확률, 적·무기·패시브 수치)가 모여 있습니다.

## 파일 구조

- `index.html`: 캔버스와 UI 오버레이(시작·레벨업·일시정지·게임오버)
- `style.css`: UI 스타일
- `game.js`: 게임 전체 (CONFIG, 오브젝트 풀, 공간 분할 그리드, 사운드, 입력, 게임 로직, 렌더링)
